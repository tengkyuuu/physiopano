# CrisisBar

Shown immediately, above everything, when a check-in answer or a typed message indicates self-harm or suicide risk. It is the only full `crisis` surface in the app.

- `crisis` fill, `on-crisis` text, `role="alert"`. Heading in `title` weight 800, one plain sentence of what happened, two actions.
- Primary action: a live hand-off to a trained human (tele-counselling partner), which opens a call or chat and creates an urgent escalation in the console. Secondary: the emergency number as text that can be copied as well as tapped.
- It does not auto-dismiss and is never hidden behind a sheet. The wristband signals never trigger it on their own: physiology alone is not crisis evidence.
- Numbers and partner names must be verified for Abu Dhabi before any demo; 998 (ambulance) and 999 (police) are the UAE emergency numbers.

Don't: soften it into a card; add breathing exercises here; show AI-generated text inside it.
